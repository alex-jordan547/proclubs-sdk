## Constructor

```ts
interface ProClubsClientOptions {
  platform?: Platform
  timeoutMs?: number
  maxAttempts?: number
  baseDelayMs?: number
  transport?: ProClubsTransport
  cache?: boolean | ProClubsCacheOptions
  onEvent?: ProClubsEventHandler
}
```

All options are optional. See [Configure the client](/docs/guides/configuration)
for defaults, constraints, and custom transport behavior.

## Request options

Every public method accepts request options as its second argument.

```ts
interface ProClubsRequestOptions {
  signal?: AbortSignal
  cache?: 'default' | 'bypass' | 'refresh'
}
```

## Return behavior

- Collection methods return an empty array when EA returns an empty collection.
- `clubs.get` and `clubs.overallStats` return `null` when no matching club is
  present in a valid response.
- Member methods return an object containing both `members` and
  `positionCount`.
- `clubs.playoffAchievements` returns an empty array when a club has no playoff
  history.
- Known response fields are typed, while additional EA fields are preserved.
- Club objects that include a `regionId` may also include a derived `regionLabel`.

## Runtime behavior

The built-in transport sends direct GET requests to
`https://proclubs.ea.com/api/fc/` using Impit's Chrome profile. It does not add
credentials, cookies, authentication, a proxy, or telemetry. The optional
cache is local to the client instance; see [Cache and observability](/docs/guides/cache-and-observability).
