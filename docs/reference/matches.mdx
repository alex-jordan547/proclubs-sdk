---
title: "Matches"
description: "List recent friendly, league, or playoff matches for a club."
---

## `matches.list`

```ts
const matches = await proclubs.matches.list({
  clubId: '12345',
  platform: 'common-gen5',
  type: 'friendlyMatch',
  limit: 5,
})
```

<ParamField path="clubId" type="string | integer" required>
  Non-empty club identifier.
</ParamField>

<ParamField path="platform" type="Platform">
  Optional per-request platform override.
</ParamField>

<ParamField path="type" type="MatchType" default="leagueMatch">
  One of `friendlyMatch`, `leagueMatch`, or `playoffMatch`.
</ParamField>

<ParamField path="limit" type="integer" default="10">
  Maximum number of results, from `1` through `10`.
</ParamField>

<ResponseField name="result" type="Promise<ClubMatch[]>">
  Recent matches. Known fields include:
  - `matchId`: Match identifier
  - `timestamp`: Unix timestamp
  - `timeAgo`: Object with `number` and `unit`
  - `clubs`: Map of club ID to `MatchClubDetails` (`date`, `goals`, `score`, `result`, `TEAM`, `winnerByDnf`, and `details` containing full `ClubInfo`)
  - `players`: Map of club ID to map of player ID to `MatchPlayerStats` (`playername`, `pos`, `rating`, `goals`, `assists`, `shots`, `saves`, `passesmade`, `tacklesmade`, `mom`, `vproattr`, `match_event_aggregate_0..3`, etc.)
  - `aggregate`: Map of club ID to `MatchAggregateStats`
</ResponseField>

```ts
for (const match of matches) {
  console.log(match.matchId, match.timestamp)
}
```

<Note>
  Match internals are loose records. All observed FC26 fields are explicitly typed
  and any future fields added by EA are preserved at runtime.
</Note>
