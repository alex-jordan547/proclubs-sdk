The package ships ESM JavaScript and TypeScript declarations from the same root
export.

## Input types

```ts
import type {
  ClubRequest,
  ListMatchesInput,
  SearchClubsInput,
} from 'proclubs-sdk'
```

| Type | Fields |
| --- | --- |
| `SearchClubsInput` | `name`, optional `platform` |
| `ClubRequest` | `clubId`, optional `platform` |
| `ListMatchesInput` | `clubId`, optional `platform`, `type`, and `limit` |

## Response types

```ts
import type {
  ClubInfo,
  ClubMatch,
  ClubMember,
  ClubMemberCareerStats,
  ClubMemberStats,
  ClubOverallStats,
  ClubSummary,
} from 'proclubs-sdk'
```

Response object types preserve unknown upstream fields. Known fields follow the
validated shapes described on the namespace reference pages.

## Response schemas

The public Zod schemas let consumers validate stored or forwarded EA payloads
against the same envelopes as the SDK.

```ts
import {
  clubInfoResponseSchema,
  clubInfoSchema,
  clubMatchesResponseSchema,
  clubMatchSchema,
  clubMemberSchema,
  clubMemberStatsSchema,
  clubOverallStatsResponseSchema,
  clubOverallStatsSchema,
  clubSearchResponseSchema,
  clubSummarySchema,
} from 'proclubs-sdk'
```

```ts
const result = clubMemberStatsSchema.safeParse(untrustedPayload)

if (result.success) {
  console.log(result.data.members)
}
```
