---
title: "Clubs"
description: "Search for clubs and retrieve club information and aggregate statistics."
---

## `clubs.search`

Find clubs by name.

```ts
const clubs = await proclubs.clubs.search({
  name: 'HEMLE FC',
  platform: 'common-gen5',
})
```

<ParamField path="name" type="string" required>
  Club name, trimmed by the SDK. Must contain from 1 through 32 characters.
</ParamField>

<ParamField path="platform" type="Platform">
  Optional per-request platform override.
</ParamField>

<ResponseField name="result" type="Promise<ClubSummary[]>">
  Matching clubs. Known fields include `clubId`, `clubName`, `platform`, `wins`,
  `losses`, `ties`, `gamesPlayed`, `gamesPlayedPlayoff`, `goals`, `goalsAgainst`,
  `cleanSheets`, `points`, `reputationtier`, `promotions`, `relegations`,
  `bestDivision`, `currentDivision`, and `clubInfo` (with `customKit`).
</ResponseField>

## `clubs.get`

Get information for one club.

```ts
const club = await proclubs.clubs.get({ clubId: '12345' })
```

<ParamField path="clubId" type="string | integer" required>
  Non-empty club identifier.
</ParamField>

<ParamField path="platform" type="Platform">
  Optional per-request platform override.
</ParamField>

<ResponseField name="result" type="Promise<ClubInfo | null>">
  The selected club or `null`. The SDK unwraps the upstream index map (`{ [clubId]: ClubInfo }`)
  to return the `ClubInfo` resource directly. Known fields include `clubId`, `name`, `regionId`,
  `teamId`, and `customKit` (with stadium name, kit IDs, kit colors, crest asset ID).
</ResponseField>

## `clubs.overallStats`

Get the aggregate record for one club.

```ts
const stats = await proclubs.clubs.overallStats({ clubId: 12345 })
```

<ParamField path="clubId" type="string | integer" required>
  Non-empty club identifier.
</ParamField>

<ParamField path="platform" type="Platform">
  Optional per-request platform override.
</ParamField>

<ResponseField name="result" type="Promise<ClubOverallStats | null>">
  The selected aggregate record or `null`. The SDK finds the matching record by club ID.
  Known fields include `clubId`, `wins`, `losses`, `ties`, `gamesPlayed`,
  `gamesPlayedPlayoff`, `goals`, `goalsAgainst`, `promotions`, `relegations`,
  `bestDivision`, `bestFinishGroup`, `skillRating`, `reputationtier`,
  `leagueAppearances`, streak stats (`wstreak`, `unbeatenstreak`), and recent match history (`lastMatch0..9`, `lastOpponent0..9`).
</ResponseField>

<Note>
  Numeric statistics can arrive from EA as a string, number, or `null`. The SDK
  preserves that upstream representation.
</Note>
