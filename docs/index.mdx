`proclubs-sdk` is an unofficial TypeScript client for the public endpoints used
by EA Sports FC Pro Clubs. It gives server-side applications a stable interface
for club discovery, rankings, rosters, statistics, and recent matches.

<Warning>
  This project is not affiliated with or endorsed by Electronic Arts. The
  upstream API is undocumented and can change or become unavailable without
  notice.
</Warning>

## What you get

## Requirements

- Node.js 22 or newer
- ESM
- A server-side runtime

<Note>
  Browser, CommonJS, React Native, Deno, and edge runtimes are outside the
  `0.1.x` support contract.
</Note>

## SDK surface

| Namespace | Method | Purpose |
| --- | --- | --- |
| `clubs` | `search` | Find clubs by name |
| `clubs` | `get` | Get one club's information |
| `clubs` | `overallStats` | Get the club's aggregate record |
| `rankings` | `allTime` | Get the all-time leaderboard |
| `rankings` | `searchAllTime` | Search the all-time leaderboard |
| `rankings` | `currentSeason` | Get the current-season leaderboard |
| `rankings` | `searchCurrentSeason` | Search the current-season leaderboard |
| `members` | `stats` | Get the current member statistics |
| `members` | `careerStats` | Get career statistics for members |
| `matches` | `list` | List recent matches by match type |

## Responsible use

Keep request volumes modest and cache data in your application when appropriate.
The SDK does not bypass authorization, access controls, or rate limits.
