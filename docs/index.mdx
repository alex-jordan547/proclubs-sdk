Build with EA FC Pro Clubs data. `proclubs-sdk` reads the public endpoints
behind EA's Clubs website and returns typed, validated responses to your
Node.js application.

Search a club, load its squad, and inspect recent matches. No EA account,
cookies, API key, or hosted relay is required.

```bash
npm install proclubs-sdk
```

```ts
import { ProClubsClient } from 'proclubs-sdk'

const proclubs = new ProClubsClient({ cache: true })
const [club] = await proclubs.clubs.search({ name: 'HEMLE FC' })

if (club) {
  const matches = await proclubs.matches.list({ clubId: club.clubId })
  console.log(matches)
}
```

Requires **Node.js 22.18.0 or newer**, ESM, and a server-side runtime.
The SDK uses a native HTTP transport; browser, React Native, and edge
runtimes are outside its support contract.

## What the SDK handles

| You need | The SDK provides |
| --- | --- |
| Club search and statistics | Club information, aggregate records, and playoff history |
| Squad and player data | Current and career member stats, plus derived nationality labels |
| Match results | Recent league, friendly, or playoff matches; raw EA fields remain accessible |
| Leaderboards | All-time and current-season rankings, with search |
| Uncertain responses | Zod validation, typed errors, bounded retries, timeouts, and cancellation |
| Repeated requests | An optional memory cache and local request events, without telemetry |

The built-in transport uses Impit with a Chrome network profile. It helps
match EA's own website requests; it cannot guarantee that EA will serve
every request. See [errors and retries](/docs/guides/errors-and-retries).

## FC 27 platform support

| EA platform | Consoles | Status |
| --- | --- | --- |
| `common-gen5` | PS5, Xbox Series X\|S, PC | Default |
| `nx` | Nintendo Switch family | Available; EA exposes no separate Switch 2 platform |
| `common-gen4` | PS4, Xbox One | Deprecated; EA returns HTTP 400 |

The EA endpoints now serve FC 27. They offer no game-version selector
or archive of your FC 26 matches. Recheck saved club IDs after each yearly
switchover. [Read the FC 27 guide](/docs/guides/fc27-api-changes).
