## What shipped in 0.2.1

- Added four ranking methods and `clubs.playoffAchievements`. The public client
  grew from 6 to 11 typed methods.
- Added exhaustive contracts for all 11 endpoints and sanitized drift reports.
- Kept unknown EA enum and region values visible without treating them as
  structural drift. Removed fields, changed types, rejected schemas, and empty
  responses still block a release gate.
- Added region, platform, match, division, reputation, playoff, and crest
  helpers.
- Added configurable live probes for `common-gen5`, `common-gen4`, and `nx`.

Read the [rankings reference](/docs/reference/rankings), [metadata
reference](/docs/reference/metadata), and [compatibility
reference](/docs/reference/types-and-schemas) for the full API details.

## Planned work

Planned items are approved for the roadmap, but have no delivery date. None is
currently in progress.

| Target | Scope | Boundary |
| --- | --- | --- |
| `0.3` | Optional relay CLI, healthcheck, route allowlist, shared-secret authentication, and Docker packaging. | The relay stays optional. The SDK continues to make direct server-side requests without it. |
| `0.4` | Circuit breaker, client-side rate limiting, stable-IP proxy support, and framework adapters. | Adds request handling and integration options around the SDK. |
| `1.0` | Stabilized public API, maintained EA compatibility matrix, and a single release and compatibility workflow. | The current on-demand probes become a maintained platform support policy. |
